# 第6章 十二運・月令・バランス

## 第40講　月令と季節評価の総合演習

### この講座で学ぶこと
本の身旺・身弱の計算法（月令点・五行点・十二運星点）を、本の例題を使って最初から最後まで計算できるようになります。合計点から身旺・中和・身弱を判定する本の判定法を使えるようにします。

### 初心者向けの導入
第5章と第6章で、身旺・身弱の計算に使う三つの項目を学びました。この講では、その三つを合計して、命式の強さを判定する練習をします。

### 理論解説
基礎編p.101の判定法は、月令点・五行点・十二運星点の三つから身旺・身弱の総合点を計算し、+3以上を身旺、0〜+2を中和、−1以下を身弱としています。

|合計点|判定|出典|
|---|---|---|
|+3以上|身旺|基礎編p.101|
|0〜+2|中和|基礎編p.101|
|−1以下|身弱|基礎編p.101|

三つの項目は次のとおりです。

- 月令点：日干の五行と月支から、月令点の表で0〜3点を読む（p.96、第36講）。
- 五行点：天干4つ・地支4つの計8文字の五行を数え、日干と同じ五行・日干を生じる五行をプラス、日干から生じる・日干が剋す・日干を剋す五行をマイナスにして差を取る（p.97〜99）。
- 十二運星点：月柱・日柱・時柱の十二運星のうち最も高い点を採る。帝旺・建禄が+2、長生・冠帯が+1、ほかは0。帝旺・建禄が2つ以上なら+3。年柱は入れない（p.100、第31講）。

### 学習資料から読む
基礎編p.96で月令点の例題を、p.98〜99で五行点の例題を、p.100で十二運星点の例題を、p.101で判定法と例題の判定を確認しました。

### 具体例1（本の例題：甲辰・癸酉・丁亥・乙巳）
基礎編p.96〜101の例題です。日干は丁（火）です。

1. 月令点：火と酉の交差で0点。
2. 五行点：8文字の五行は木2・火2・土1・金1・水2。プラスは火（日干と同じ）2と木（日干を生じる）2で4、マイナスは土1・金1・水2で4。4−4＝0点。
3. 十二運星点：月支酉は長生（+1）、日支亥は胎（0）、時支巳は帝旺（+2）。最も高い+2。年支辰の衰は入れない。
4. 合計：0＋0＋2＝+2で、中和。

### 具体例2（本の例題：丙戌・甲午・丁丑・庚子）
日干は丁（火）です。

1. 月令点：火と午の交差で3点。
2. 五行点：木1・火3・土2・金1・水1。プラスは火3と木1で4、マイナスは土2・金1・水1で4。0点。
3. 十二運星点：月支午は建禄（+2）、日支丑は墓（0）、時支子は絶（0）。+2。
4. 合計：3＋0＋2＝+5で、身旺。

### 命式でどこを見るか
日干、月支、8文字の五行、月・日・時支の十二運星を確認します。空亡の支や三合・方合がある場合の扱いは、本のp.101〜103に従います（第7章で学びます）。

### 判断手順
1. 日干の五行を確認する。
2. 月令点を表で読む。
3. 8文字の五行を数えて五行点を計算する。
4. 月・日・時支の十二運星から十二運星点を求める。
5. 三つを合計し、+3以上は身旺、0〜+2は中和、−1以下は身弱とする。

### よくある間違い
蔵干を五行点に数える（本では天干4・地支4の8文字）、年柱の十二運星点を入れる、十二運星点を三つの柱の合計にする（本では最高点だけ）、月令点だけで判定する、という誤りに注意します。

### まとめ
本の身旺・身弱は、月令点・五行点・十二運星点の合計で判定します。+3以上が身旺、0〜+2が中和、−1以下が身弱です。

### 次の講座とのつながり
次講では、日干の「根」について、本の説明を学びます。

### 出典管理
原典確認済み：基礎編p.96（月令点）、p.97〜99（五行点）、p.100（十二運星点）、p.101（判定法と例題の判定）。八雲式鑑定エンジンの本どおりの身旺・身弱の判定は、これらの例題の点数をすべて再現します。

### 実践演習
**問題**：基礎編の例題「甲辰・癸酉・丁亥・乙巳」の月令点・五行点・十二運星点と合計点、判定を答えてください。

**模範解答**：月令点0、五行点0、十二運星点+2、合計+2で中和です。

### 章末総合演習
**問題**：例題「丙戌・甲午・丁丑・庚子」の身旺・身弱を、三つの項目の計算から判定してください。

**模範解答**：月令点3（火と午）、五行点0（プラス4−マイナス4）、十二運星点+2（月支午の建禄）、合計+5で身旺です。
