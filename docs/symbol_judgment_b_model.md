# 八雲式B範囲・研究モデル v1（レビュー改訂2）

これは原典再現でも本番鑑定でもなく、明示した八雲式仮定を用いる独立研究モデルである。
原典観測55件の比較は従来どおり `hold` とし、このモデルの出力で補完しない。

## 入力と実行

```json
{"pillars":{"year":"甲辰","month":"癸酉","day":"丁亥","hour":"乙巳"},"element_roles":{"useful":["木"],"favorable":["火","水"],"unfavorable":["土","金"]},"great_luck":"甲子","annual":"庚午"}
```

```powershell
python -m scripts.symbol_judgment_b_model input.json
Get-Content input.json -Raw | python -m scripts.symbol_judgment_b_model -
```

`element_roles` を省略した場合だけ、日主の強弱に基づく扶抑法の仮定で推定する。強弱が境界域、
入力不足、分類競合、特殊格局指定は `hold`。重みと閾値は `--config config.json` で上書きできる。

## 記号境界（独自仕様）

- `◎`: score >= 3
- `○`: 1 <= score < 3
- `△`: -2 < score < 1
- `×`: score <= -2
- `hold`: 四段階の外。推測で中間記号にしない。

改訂2では、干合・支合・冲・刑・自刑の効果方向は相手の五行分類に依存する独自仮定。
合は一律に吉、冲刑は一律に凶としない。合化は未判定で五行を変換しない。
同一文字組・作用は一度だけ数える（位置差と争合は未対応）。規則、根拠区分、優先順位、制約は出力の
`rule_catalog`、採用値は `config`、個別適用は `applied_rule_ids` で追跡できる。

## レビュー改訂2の仕様

互換モデルIDは維持し、`revision: b-review-2`で識別する。
月支の旺相休囚死に1.2/1.1/1/0.9/0.8の係数を適用する。
係数幅はseasonal_strength_weightで変更可能。補正前後で強弱区分が変わる場合は推定hold。
蔵干配分は1個なら1、2個なら7:3、3個なら6:3:1。配分は独自仮定。
地支評価と大運・流年の基礎点に蔵干を反映し、期間は天干4割・地支6割とする。
大運＋流年の統合行は、期間基礎点と対命式作用の平均＋流年から大運への作用を一度だけ加算。
個別期間スコアをそのまま足して相互作用を重複計上しない。
未分類五行は忌神とせず個別hold。不足五行が忌神なら不足を加点しない。
不正分類・非有限設定・閾値順序違反・陰陽不整合干支はhold。
UTF-8 BOMファイル入力に対応。不正JSONと全体holdのCLI終了コードは2。
個別holdを含む全体provisionalは終了コード0になり得る。各評価のstatusも確認する。
旧transformation成立=falseは変換未適用を表し、transformation_status=not_evaluatedが判定状態。

特殊格局、合化成立条件、調候、三合・三会・害・破、土用細分化、大運開始時期、
独立した鑑定精度検証は未対応。命式自体の再構成は行わず、対象との局所作用を評価する。
原典観測55件は既存研究のメタ情報であり、独自出力から比較可能へ昇格しない。
