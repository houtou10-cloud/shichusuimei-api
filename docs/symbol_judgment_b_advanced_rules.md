# Bモデル高度規則（研究用暫定仕様）

本書は `scripts/symbol_judgment_b_model.py` の合化・調候・特殊格局を説明する。原典の記号再現規則ではなく、既存エンジンの観測可能な規則と、ユーザーが採用を許可した八雲式研究仮定を分離して記録する。本番engine、API、鑑定では使用しない。

## 優先順位

1. 入力検証（100）: 不正・不足はhold。
2. 明示特殊格局（95）: 成立時は通常の `element_roles` より優先する。
3. 命式内天干合化（90）: 成立した場合だけ五行分布を置換する。
4. 調候（85）: 特殊格局と衝突する調候補正は抑止する。
5. 五行バランス・月令（80）、扶抑・用神（70）、蔵干（60）、合冲刑（50）、運（40）、記号化（10）。

上位規則で解決できる競合は上位を採用する。争合、特殊格局の不成立、化気格に必要な合化が一意に成立しない場合は、理由コードを付けてholdとする。候補止まりの合化は五行量へ反映しない。

ここでの数値は競合解決の優先度であり、計算依存順とは区別する。計算は「入力検証 → 合化証拠と合化後分布 → 特殊格局 → 調候 → 通常評価」の一方向である。化気格は合化後分布を読むが、特殊格局の結果が合化成立条件へ戻ることはなく、循環しない。日干の合化が成立しているのに化気格以外の特殊格局が指定された場合は、両立規則がないため `non_transforming_special_structure_conflicts_with_day_stem_transformation` でholdとする。

## 合化

### 再利用した既存規則

- 五合の化神: 甲己→土、乙庚→金、丙辛→水、丁壬→木、戊癸→火。
- `engine.stem_transformation.evaluate_month_support` による月支代表五行と化神の同気・生・非支持の区分。
- 既存engineが合と合化を分離し、月令・通根・透干・競合を別証拠として扱う設計。

### 採用した八雲式研究仮定

合化成立は、命式内天干五合について次をすべて満たす場合に限定する。

1. 月支代表五行が化神と同一（`strong`）。月支が化神を生じるだけの `supportive` は候補止まり。
2. 四支の蔵干に化神五行が一つ以上あり、通根する。
3. 合の参加二干以外に化神五行の天干が一つ以上透出する。
4. 参加干が別の五合候補にも参加する争合がない。

成立時は参加二干の季節補正後五行量を先に除き、化神二干分を一度だけ加える。除去・加算量は `transformation_accounting` に記録し、参加干の旧五行を残さない。命式外の大運・流年天干、支合化、妬合の細分類、遠近・隣接条件は未対応である。争合は合化後五行分布が一意に定まらず、全評価対象がその分布を共有するため、無関係に見える対象も含むモデル全体を `unresolved_competing_stem_combination` でholdにする。返却値の `hold_scope` と `hold_explanation` に範囲と理由を記録する。通根・透干等の証拠不足は対応する理由を持つhold候補として保持し、分布には適用しない。

## 調候

### 再利用した既存規則

`engine.climate_useful_gods.evaluate_climate_useful_gods` の月支ベース寒暖燥湿プロファイル、必要機能、調候五行順位をそのまま利用する。原典の日干別調候表を再現したものではない。

### 採用した八雲式研究仮定

- 第一候補五行へ既定 `+0.5`、第二候補へ `+0.25` を成分点として加える。
- 値は `climate_weight` で変更でき、負値は禁止する。
- 特殊格局が成立し、その忌神と調候候補が一致する場合は、優先順位に従い特殊格局を採用して調候加点を抑止する。
- 調候は用神分類そのものを上書きせず、小幅な評価補正に限定する。
- 十干・地支は各対象の成分比率へ一度だけ加点する。大運・流年も各期間の天干・蔵干成分比率の合計へ一度だけ加点し、統合評価では両期間の調候込み成分点を1/2ずつ平均する。統合時に別の調候加点は追加しない。

土用月の遷移、日干別の詳細優先表、命式全体による寒暖燥湿の再計算は未対応である。

## 特殊格局

自動検出は行わず、入力 `special_structure.type` で明示された場合だけ評価する。対応する名称は `従旺格` / `従強格`、`従児格`、`従財格`、`従殺格` / `従官殺格`、`化気格`（技術名も可）である。

- 従旺・従強: 日主＋印の支持比率が0.80以上、かつ日主五行比率が0.40以上。
- 従児・従財・従官殺: 日主＋印の支持比率が0.20以下、かつ対象五行比率が0.50以上。
- 化気: 日干が参加する合化が上記条件でちょうど一件成立し、化神比率が0.50以上。

成立時は対象五行を用神、その対象を生じる五行（従旺は印）を喜神、残りを忌神とする。明示された通常 `element_roles` と競合した場合は特殊格局を優先し、`overrides_element_roles` に記録する。未知類型、比率不足、宣言五行不一致、化気合化の不存在・複数成立は理由付きholdであり、記号を生成しない。

## 残る未対応

- 支合化と大運・流年を含む合化。
- 日干別・季節別の詳細調候表と土用遷移。
- 特殊格局の自動候補抽出、真従・仮従、破格・復格、流派別条件。
- 原典の◎○△×変換規則との比較。原典55観測との比較状態は引き続きhold。
