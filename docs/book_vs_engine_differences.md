# 『四柱推命 基礎』と八雲式鑑定エンジンの違い

作成日：2026-10-16
位置づけ：研究用の調査記録。本番エンジン（`engine/`）は変更していない。
方針（ユーザー指示）：**基本は本どおりにする。**

## 1. 結論

講座の第3章（時柱）と第4章（蔵干）を本で確認した結果、本の手順と本番エンジンの計算に、次の2領域・4点の違いがあった。

| No. | 領域 | 本（原典） | 本番エンジン | 影響の大きさ |
|---|---|---|---|---|
| A1 | 時柱 | 午後11時〜0時は、表の「午後11時〜0時」の欄（翌日の日干の子）。例：甲日は丙子 | 23時台は同じ日の子。例：甲日は甲子 | 23時台の生まれ全員（約4%） |
| A2 | 時柱 | 区切りちょうどの時刻は前の時間帯（1時ちょうど→子） | 時（hour）だけで判定（1時ちょうど→丑） | ちょうどの時刻の生まれのみ（まれ） |
| A3 | 時柱 | 昭和23〜26年のサマータイム期間は生時を1時間繰り下げる | 補正なし | その期間の生まれの一部 |
| B1 | 蔵干 | 節入からの日数で、月律分野蔵干表の初期・中期・正期から1つを選ぶ。同じ日数を四つの地支に当てはめる | 地支ごとの主蔵干（＝正期）を常に使う | 約半数の命式で、どこかの柱の蔵干が変わる |

数字は §4 の比較による。

## 2. 原典の根拠

- 時柱：基礎編p.48（日干をもとに干支時刻表を使う。日干丁・午前10時→乙巳）、p.49（干支時刻表、区切りの時刻の注記、サマータイムの実施期間と1時間繰り下げ）。
- 蔵干：基礎編p.50（蔵干の定義、節入前は前月の節入日から・節入後はその月の節入日から日数を数える）、p.50〜51（例題：10月5日生まれ、前月9月7日の節入から30−7＋5＝28日目、辰＝戊・酉＝辛・亥＝壬・巳＝丙）、p.52（月律分野蔵干表、阿部泰山式、初期・中期・正期）。
- 節入日時：本番エンジンの天文計算は、本の万年暦（p.47）の節入時刻と一致することを例題で確認（1964年9月の節入：本「7日 午後11:59」、エンジン 9月7日23:59）。

## 3. 本どおりの計算（研究用実装）

- 実装：`scripts/book_method_rules.py`
  - `book_hour_pillar(day_stem, birth, apply_summer_time=True)`：A1〜A3を本どおりに計算。
  - `days_since_setsuiri(birth)`：p.50の数え方。節入日からの日付の差（節入日当日は0日目）。
  - `book_hidden_stem(branch, days)`、`book_hidden_stems_for_chart(birth, branches)`：B1を本どおりに計算。
- テスト：`tests/test_book_method_rules.py`（本の例題・表の値をすべて再現。7件通過）。
- 比較：`scripts/compare_book_vs_engine.py`（本番エンジンを呼び出して食い違いを数える）。

### 本から一意に決められない点（hold）

| 点 | 扱い |
|---|---|
| 午前0時ちょうどの生まれ | 前日の「午後11時〜0時」か当日の「午前0時〜1時」か本から決まらない → hold |
| サマータイムの繰り下げで日付が変わる場合（例：0時30分→前日23時30分） | 日柱をどうするか本から決まらない → hold |
| 午後11時〜0時の生まれの日柱 | 本の表は時柱の干だけを示す。日柱は当日のままと読める（エンジンの日界0時と同じ）。日柱の扱いを変える根拠は本にない |
| 節入日当日を何日目と数えるか | 本の例題の式（日付の差）に合わせて0日目とした。当日生まれの扱いを直接示す記述は未確認 |
| サマータイム期間の境界日の時刻 | 本は日付だけを示す。期間の開始日・終了日は終日を期間内として扱った |
| 年柱・月柱へのサマータイムの影響 | 本は「時柱干支を設定する」とだけ述べる。年柱・月柱・日柱には適用していない |

## 4. 影響の大きさ（比較結果）

`scripts/compare_book_vs_engine.py` を、1930〜2029年の出生日時3000件（分単位の一様乱数、seed=20261016）で実行した。

### 4.1 結果

| 項目 | 件数 | 割合 |
|---|---|---|
| 時柱が違う | 148 | 4.9% |
| 　うち A1：23時台の子の刻 | 116 | 3.9% |
| 　うち A2：区切りちょうどの時刻 | 19 | 0.6% |
| 　うち A3：サマータイム | 13 | 0.4% |
| 時柱が hold（本から決まらない） | 7 | 0.2% |
| 蔵干がどこかの柱で違う（B1） | 1,587 | 52.9% |
| 月支の蔵干が違う（B1） | 1,297 | 43.2% |

柱ごとの蔵干の違い：年 1,319件、月 1,297件、日 1,314件、時 1,315件。

読み方：
- 時柱の違いは約20人に1人で、ほとんどが23時台の生まれ。
- 蔵干は、節入から日の浅い（おおむね14日目まで）生まれで初期・中期の干になるため、約半数の命式で変わる。月支の蔵干は格局の判定に使われるため、本番への影響は蔵干のほうがはるかに大きい。
- 割合は一様乱数の標本による推定で、実際のお客様の生年月日の分布とは異なる。

## 5. 本どおりにした場合に影響する本番の範囲

本番エンジンで、蔵干・時柱の値を使っている箇所：

- 蔵干（主蔵干）：`engine/pillars.py`、`engine/hidden_stems.py`、`engine/pattern_candidates.py`、`engine/pattern_judgment.py`（格局）、`engine/annual_luck.py`、`engine/reading_context.py`、`engine/reading_context_v2.py`、`engine/reading_product.py`、`engine/reading_renderer.py`。
- 時柱：`engine/hour.py`、`engine/pillars.py`。

B1（蔵干）を本どおりにすると、月支の蔵干が変わる命式で、格局の判定（月支蔵干と透干）、蔵干の通変星、強弱の材料が変わる。既存のゴールデン・フィクスチャ（`tests/golden`、`tests/fixtures`、Frozen v1.2 のゴールデン）の期待値も変わるため、AGENTS.md の「既存Fixture・本番engine・Frozen v1.2 は変更禁止」と衝突する。

## 6. 本どおりモードの追加（2026-10-16）

ユーザーの指示（本通りでお願い）により、本番エンジンに「本どおりモード」を追加した。既定の計算は変えていない。

- `engine/book_rules.py`：本どおりの時柱・蔵干の規則（研究用 `scripts/book_method_rules.py` はこれを使う）。
- `engine/pillars.py`：`calculate_four_pillars(..., rule_set="book_kiso")` で本どおりの時柱と蔵干に置き換える。蔵干は本の表で選んだ1つだけを `hidden_stems` に入れる。時柱が本から決まらない場合は従来の時柱を残し、`warnings` に理由を書く。
- `engine/chart.py`：`calculate_chart(req, rule_set="book_kiso")` で命式全体を本どおりモードで計算できる。`rule_set` を指定しなければ従来どおり。
- テスト：`tests/test_pillars_book_rule_set.py`（5件）。既定の出力が従来と完全に同じことも確認。テスト全体は7387件通過（追加前と同じ）。

### 6.2 注意：強弱の計算は本の方法ではない

主蔵干が変わらない鑑定例（GC02・GC03）でも強弱が変わった。本どおりモードでは各地支の蔵干が1つだけになり、従来の強弱の計算（複数の蔵干を重み付けして根の強さを数える八雲式の点数モデル）に入る材料が減るためである。

この強弱の点数モデルは本の方法ではない。本は身旺・身弱を別の方法（例題の「中和＋2」のような点数）で求めている（基礎編p.78・p.94を参照する記述あり、計算方法の本文照合は未実施）。時柱と蔵干だけを本どおりにし、強弱は八雲式の点数モデルのまま、という組み合わせは、本どおりでも従来どおりでもない中間の結果になる。GC04 の「身強→身弱」のような大きな変化は、この組み合わせの影響と考えられる。

### 6.3 強弱も本の方法に（2026-10-16 追加）

ユーザーの指示（本通り一貫で）により、本どおりモードの強弱を、本の身旺・身弱の計算法に置き換えた。

- 原典：基礎編p.95（判断の基準：月令の有無・五行の分布・十二運星の強弱）、p.96（月令点の表）、p.97〜99（五行点：天干4・地支4の計8文字で、自星＋印星 − 泄星・財星・官星）、p.100（十二運星点：帝旺・建禄＝+2、長生・冠帯＝+1、他は0。月・日・時柱の最高点のみ、帝旺・建禄が2つ以上なら+3。年柱は数えない）、p.101（判定法：+3以上 身旺、0〜+2 中和、−1以下 身弱）、p.101〜102（空亡：年支・時支のみ、支・蔵干・十二運星とも存在しないとみる。月支は空亡としない。支合・三合・方合・冲で解空）、p.103（三合・方合はその五行に+1、月支が旺支の三合・方合は+2）。
- 実装：`engine/book_strength.py`。`calculate_chart(req, rule_set="book_kiso")` のとき、`final_strength_judgment` を本の判定に置き換える。本の点数は `book_total_score`、内訳は `book_strength` に入る。
- 下流（格局・用神など）は 0〜100 の点数を補助的に読むため、`final_score` には区分の代表値（身旺64・中和50・身弱36）を入れ、`score_scale="book_kiso_label_representative"` と明記した。
- テスト：`tests/test_book_strength.py`。本の例題6件（p.98〜103。空亡・月支の空亡・三合水局・火方合と冲による解空を含む）の点数をすべて再現（7件通過）。
- 本から決まらない点：p.95「丑・辰は壬・癸の日干の根となるので、その点を加味しながら計算する」は加味の方法が書かれていないため点数に反映せず、notes に記録して confidence を medium にする。三合・方合は三支がそろう場合のみとした（半合の扱いは本に記載なし）。

### 6.5 格局も本の方法に（2026-10-16 追加）

- 原典：基礎編p.104（格＝タイプ。一般には月支の通変星＝元命で格を決める。内格の取り方の基本①〜⑤）、p.105（内格・外格、例題：元命の偏財で偏財格）、p.105〜106（例題：劫財に剋される正財は破格の正財タイプ）。
- 実装：`engine/book_pattern.py`。本どおりモードの `pattern_judgment` の主要キー（`primary_pattern` など）を本の格で置き換え、根拠を `book_pattern` に入れる。
  - ① 元命（本どおりモードの月支の蔵干）の通変星。
  - ② 地支の三合・方合（三支がそろう場合）は、その四旺（子・卯・午・酉）の正気で決める。
  - ③ 月支の初気だけが年干・月干・時干に透っていれば初気で決める。
  - ④ 三つの気がすべて透っていれば元命（生日）で決める。
  - ⑤ 二種が透っている場合は判定方法が本にないため hold（元命で仮に決め、confidence を medium にする）。
  - 破格：吉星（偏財・正財・印綬・正官・食神）の格で、それを剋す星（比肩・劫財・正財・傷官・偏印）が天干にあれば `is_broken=True`。
  - 比肩・劫財の格（本の「比肩タイプ」「劫財タイプ」）は、既存の格局用神の規則の建禄格・羊刃格（jianlu・yangren）に対応づけた（八雲式の対応づけ）。
  - 外格（特殊な格）は条件が本のこの範囲にないため判定していない（`outer_pattern_checked=False`）。
- テスト：`tests/test_book_pattern.py`（本の例題2件と規則②③⑤。5件通過）。例題の昭和6年3月26日生まれは、本どおりモードの四柱が本の命式（辛未・辛卯・庚辰・壬午）と一致し、破格の正財格になる。
- 鑑定例：GC03 は時干の丁が月支未の初気（丁）と同じため、規則③で「食神格→比肩格」になった。他の4件は格局が変わらない。
